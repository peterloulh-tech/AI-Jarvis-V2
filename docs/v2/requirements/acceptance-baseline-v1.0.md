## 4. 正式执行与阶段出口

每个 case 必须锁定环境、应用提交/构建、模型/量化/运行时、配置、输入/故障版本、样本规则和证据根路径。结果只允许 `通过`、`失败`、`阻塞`、`不适用`：

- `通过`：该精确 case 的冻结结果与证据完整；不得外推到未执行组合。
- `失败`：冻结结果不满足、出现范围违规或任一 P0 失败；后续成功不得覆盖。
- `阻塞`：关键实现、资产、环境、步骤、字段或证据缺失，无法形成结论。
- `不适用`：仅用于冻结明确排除或正式支持范围外的探索环境；缺少必测条件不得使用。

阶段出口必须同时满足：57/57 P0 全部 `通过`；V10、O10、C10 三项 P1 均已测试并保留原始数据与四态结论；4 小时正式窗口完成且主程序崩溃为 0；不存在显存无法释放、持续误采集、无法停止、无界增长或 P0 失败。8 小时只作为内部压力证据，不替代 4 小时，也不形成对外承诺。任一条件未满足，产品验收出口为 `阻塞` 或 `失败`，不得进入发布结论。
