## 编号与计数口径

- `FR-章节.小节`：功能冻结版的最细编号章节；无小节的章节使用 `FR-章节`。一个 ID 覆盖该源章节内的全部正文、列表、表格和公式。共 **83** 个功能追踪单元，24 章全部覆盖。
- `NFR-章节.小节`：非功能冻结版的最细编号章节；无小节的章节使用 `NFR-章节`。一个 ID 覆盖该源章节内全部条款。共 **14** 个非功能追踪单元。
- `AC-A01` 等：候选验收清单原有 A/B/V/O/C/R/D 编号加统一前缀。共 **60** 个候选验收项。
- `OOS-###`：从功能冻结版检出的显式“不做/不开发/不支持/禁止/不得”边界。
- `CAL-###`：尚未冻结、必须依赖模型、回放或 Windows 真机实测的指标。
