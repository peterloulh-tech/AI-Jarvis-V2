场景只固定输入、分组、测量点和统计口径。未冻结的采样次数、采样间隔、预热规则和最终门槛应在执行方案中填写并经评审，不在本任务预设。

## 1. 通用场景契约

每次执行必须生成唯一 `scenario_run_id`，并记录场景 ID、回放/输入哈希、环境、版本、模型、量化、运行时、配置快照、预热规则、采样规则、开始/结束时间、异常、证据路径和结果标记。场景内任何控制变量变化都必须新建 `sample_group`。

基准测试不以在线内容或不可复现的直播流作为唯一输入；端到端与模型质量场景使用固定录像及人工金标。需要 Windows 真机的资源、采集与显示结果不得由非 Windows 环境替代。

## 4. 覆盖结论

冻结功能需求第 23.2 节登记的 CAL-006～CAL-024 已由 BENCH-001～019 一一覆盖；CAL-001～005 的启动、加载、首弹幕、端到端和停止清理由 BENCH-020～023 补充。CAL-025～030 属于质量、模型/运行时选型或安装包事项，不在本任务内得出结论。
