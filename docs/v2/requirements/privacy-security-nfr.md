## 2. 隐私与安全原则

1. **本地优先。** 完整安装后，Local O / Local V 核心闭环不要求账号、登录或联网；断网不得改变 Local 核心数据流语义。
2. **无自动外传。** 第一版不包含遥测、崩溃自动上报、诊断自动上传、后台版本服务或未经用户操作的第三方发送。
3. **原始音画默认不持久化。** 截图、麦克风、游戏进程音频和系统混合音频在本地只可于当前处理所需的有界内存/显存中存在，默认落盘事件数为 0；Local 上传为 0，Online 仅允许用户主动选择后的当前推理必需上传。
4. **最小驻留。** 每类数据必须登记来源、用途、允许驻留位置、上限、清除时机和导出规则；无明确用途或无边界的数据不得采集或保留。
5. **显式导出。** 诊断包只能在停止状态由用户主动导出到本地选择的位置；默认不含原始音画和弹幕文字，弹幕文字仅在用户明确勾选后进入本次包。
6. **本机边界。** 主程序、采集、模型和 Overlay 之间只允许本机进程通信；不得监听非本机接口或把 IPC 变成远程服务入口。
7. **元数据优先。** 日志、指标和诊断只记录定位问题所需的结构化元数据；性能和故障判定不得依赖原始音画或弹幕原文。
8. **完整性先验证后使用。** 程序依赖、运行时和模型包必须具有可追溯来源、版本和发布清单摘要；实际安装/加载前的验证结果必须可记录，摘要不匹配时不得把包标记为可用。
9. **Online 明确边界。** 只有用户选择 Online 并点击开始后才允许使用用户自己的 API Key 连接已选 Provider；暂停时停止新上传，停止、退出或切回 Local 后关闭远程会话；失败必须明确反馈且不无限重试。

## 4. 采集权限与本机 IPC 约束

| 边界 | 最小允许信息 | 禁止项 | 审计字段 |
|---|---|---|---|
| 用户 → 主程序 | 用户选择的画面源、音频源、模式和本次控制动作 | 未点击开始前采集；扩展到未选择来源 | run_id、config_snapshot_hash、source_type、source_id 摘要、control_action |
| 采集 → 编排/模型 | 当前任务所需的有界帧、音频块、顺序号和时间戳 | 原始音画写日志；建立长期队列；Local 发送到外部网络；Online 发送到非当前已选 Provider | endpoint_id、peer_process、payload_class、capture_sequence、limit |
| 主程序 ↔ 模型服务 | 本次推理输入、任务 ID、结构化结果和必要错误元数据 | 未授权远程监听；把本机路径、账号标识或无关窗口信息混入载荷 | task_id、service_id、peer_process/provider_endpoint、payload_class、outcome |
| 主程序 → Overlay | 要显示的批次/文本和显示所需元数据 | 原始画面/音频；远程端点；诊断包内容 | batch_id、message_id、endpoint_id、payload_class |
| 主程序 → 本地存储 | 配置、滚动元数据日志、最小异常锁标记、用户主动导出的诊断包 | 默认原始音画、无限日志、自动上传缓存、长期历史 | data_class_id、path_class、configured_limit、clear_trigger、export_selection |

IPC 实现必须记录端点类型、绑定范围、对端进程和载荷类别。操作系统命名管道、共享内存或仅环回套接字均属于待实现选择；本文不把任一方案声明为已验证安全。

## 5. 日志脱敏规则

日志采用字段允许列表。以下内容不得进入普通运行日志、性能记录或默认诊断包：

- 原始截图、视频帧、麦克风录音、游戏音频和系统混合音频；
- 提示词、模型输入正文、模型输出正文、弹幕正文和用户可识别的自由文本；
- 访问令牌、密钥、凭据、完整命令行、完整本机用户名和未经归一化的绝对路径；
- 未经需求登记的窗口标题、进程参数、剪贴板内容、文件内容或网络负载正文。

允许记录的排错元数据包括版本、稳定错误码、组件、模式、计数、时点、耗时、队列深度/上限、重启次数、进程 ID、硬件型号/容量和配置快照摘要。确需关联的路径、来源或端点使用类别、稳定摘要或局部归一化值，不记录原始用户内容。

| 对象 | 发布清单最小字段 | 使用前验证 | 失败处理 | 本任务不作的结论 |
