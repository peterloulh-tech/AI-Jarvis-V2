## 2. 恢复目标与记录规则

| 目标 | 冻结结果 | 量化状态 | 证据 |
|---|---|---|---|
| 主界面可操作 | 组件故障后仍可执行停止或退出 | 具体响应耗时待实测 | MP-03/04/19；MET-S04 |
| 故障不扩散 | 单组件异常不拖死主程序及无需停止的组件 | 逐次通过/失败，无平均豁免 | MP-19～21；MET-S05 |
| 恢复代次隔离 | 恢复/复位后旧代次结果不得生效 | 旧结果接受数固定为 0 | run_generation、MP-09/12/13/14/17/21 |
| 停止清理 | 模型、显存和相关子进程完成清理 | 清理结果冻结；耗时待实测 | MP-03/04/23；MET-T11/R03/S06 |
| 异常退出清理 | 再启动时清理上次遗留且不复用旧运行状态 | 逐次通过/失败 | MP-01/02/23；MET-S07 |
| 单实例 | 第二次启动不形成第二实例或第二模型 | 新增数固定为 0 | 进程/模型/会话枚举；MET-C08 |
| 有界保护 | 等待、队列、日志、历史和重启保护不得无限增长 | 必须有界冻结；具体上限待后续评审 | MP-22；MET-R08/R09、S08/S09 |

## 3. 故障不扩散检查清单

- [ ] 故障前已记录主程序、模型、采集和 Overlay PID/角色及当前 `run_generation`。
- [ ] 故障由冻结已有信号触发，没有新增模型探测、看门狗推理或额外业务状态。
- [ ] MP-19、期望动作、实际动作、错误码和证据引用完整。
- [ ] 故障期间主界面可接受暂停、停止或退出；无需停止的组件状态符合矩阵。
- [ ] 恢复、暂停或全局复位后旧代次结果未进入校验、队列或 Overlay。
- [ ] 每个等待和重试结构记录配置上限、当前值、峰值、触顶和退出原因。
- [ ] 停止或退出后 MP-23 完整，模型专属显存、剩余 PID 和孤儿结果可核验。
- [ ] 任何恢复耗时、资源增长或 V 保护阈值没有被升级为最终门槛。
