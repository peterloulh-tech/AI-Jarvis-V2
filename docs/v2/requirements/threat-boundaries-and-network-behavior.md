# AI Jarvis V2 威胁边界、数据流与网络行为清单

> 任务：AIJARVISV2-6
> 说明：本文件是威胁建模和验证入口，不声称当前实现已抵御全部攻击或已不存在未声明网络行为。

## 1. 信任与威胁边界

| ID | 边界 | 受保护对象 | 主要风险 | 第一版约束 | 验证入口 |
|---|---|---|---|---|---|

| TB-002 | 采集进程 → 编排/模型 | 原始画面和音频 | 落盘、无限缓存、未授权外传 | 本机有界 IPC；载荷类别登记；Local 不上传；Online 仅向当前已选 Provider 发送必需载荷 | IPC-TEST-001～003；DISK-TEST-001～003；NET-TEST-004 |
| TB-003 | 主程序 ↔ 模型服务 | 模型输入、结果、任务/错误元数据 | 未授权远程暴露、对端混淆、无关用户内容泄漏 | Local 对端限本机；Online 对端限当前已选 Provider；不得监听非本机接口；只传当前任务最小载荷 | IPC-TEST-001～003；NET-TEST-003/004 |

| TB-006 | 应用 → 外部网络 | 本地数据和运行元数据 | 未授权 Provider、遥测、自动上传、后台检查、错误后静默持续产生费用 | Local 外连为 0；Online 仅在用户主动选择并开始后连接已选 Provider，暂停/停止后停止上传 | NET-TEST-001/002/004 |

## 2. 数据流清单

| Flow ID | 来源 → 目的 | 数据类 | 触发/持续时间 | 允许边界 | 持久化/外传规则 |
|---|---|---|---|---|---|
| FLOW-001 | 用户选定画面源 → 采集组件 | DATA-001 | 用户点击开始后至暂停/停止边界 | 本机内存 | 默认不落盘、不上传 |
| FLOW-002 | 用户选定音频源 → 采集组件 | DATA-002～004 | O 模式开始后至暂停/停止边界 | 本机内存 | 默认不落盘、不上传 |
| FLOW-003 | 采集组件 → 模型/编排 | DATA-001～005 | 当前推理任务 | 本机有界 IPC/内存/显存 | 任务完成或清理边界删除 |
| FLOW-004 | 模型 → 编排/发送 | 结构化事件、批次和最小元数据 | 当前任务完成后 | 本机 IPC/内存 | 只进入有界轻量历史和滚动日志；正文不默认导出 |
| FLOW-005 | 编排 → Overlay | 弹幕文字、批次/显示元数据 | 实际显示窗口 | 本机 IPC | 不携带原始音画；不外传 |
| FLOW-006 | 组件 → 滚动日志 | DATA-010 | 运行期事件 | 本地受控运行期区 | 允许列表、配置上限、关闭清除 |
| FLOW-007 | 生命周期 → 锁标记 | DATA-011 | 启动/异常退出/正常关闭 | 本地最小状态区 | 不含用户内容；处理后清除 |
| FLOW-008 | 用户选择 → 诊断包目标 | DATA-012 | 停止状态单次导出 | 用户选择的本地路径 | 不上传；默认无原始音画和弹幕正文 |
| FLOW-009 | 发布清单 → 包验证器 | DATA-013/014 | 安装/替换/首次加载前 | 本机文件读取 | 只产生完整性结果元数据 |
| FLOW-010 | Online 适配器 ↔ 已选 Provider | DATA-001～004 当前推理必需载荷、结构化结果和错误元数据 | 用户选择 Online 并点击开始后至暂停/停止边界 | 已选 Provider 官方端点 | 不上传诊断包、历史、日志或无关本地内容；停止后新上传为 0 |

## 3. 网络行为清单

| NET ID | 场景 | 触发主体 | 允许网络行为 | 本地数据载荷 | 结果边界 |
|---|---|---|---|---|---|
| NET-001 | 配置页、Local O / Local V 核心运行、暂停/恢复/停止 | 用户的本地操作 | 无外部网络；可使用经确认的本机 IPC | 不适用 | 外部出站/入站连接数为 0 |
| NET-002 | 运行日志与轻量历史 | 应用 | 无网络 | 不适用 | 无遥测、无崩溃自动上报、无内容上传 |
| NET-003 | 手动诊断导出 | 用户在停止状态操作 | 仅本地文件写入 | 脱敏字段；弹幕文字按勾选 | 无上传、无在线服务依赖 |
| NET-004 | 自动更新/版本检查/模型下载 | 应用后台 | 第一版禁止 | 不适用 | 后台请求数为 0；手动安装/更新流程由任务7定义 |
| NET-005 | 账号、登录、许可证或在线授权 | 应用 | 核心运行不需要 | 不适用 | 账号/登录依赖数为 0 |
| NET-006 | 组件 IPC | 本机组件 | 仅本机端点；若使用套接字只能绑定本机范围 | 见 FLOW-003～005 | 非本机监听和远程对端数为 0 |
| NET-007 | Online 多模态运行 | 用户选择 Online 并点击开始 | 仅连接已选 Provider 必需端点；使用用户自己的 API Key | 当前模型工作必需音画，不含诊断包/历史/日志 | 暂停后新上传为 0；停止、退出或切回 Local 后会话关闭；失败明确反馈且重试有上限 |

实际实现若出现本表未登记的域名、IP、端口、协议或远程端点，必须判为 `REVIEW_REQUIRED`；若携带本地数据且不属于 FLOW-010 / NET-007，或属于自动上传/遥测，则判为 `FAIL_FROZEN`。不得通过补写本表把违规外连事后合理化。

## 4. 断网与未声明外连验证

### NET-TEST-001：断网核心闭环

前置条件：完整安装，所选模型已在本机并完成完整性核对；不登录账号；保存构建、模型、OS/GPU 和网络接口清单。

步骤：

1. 在应用启动前禁用外部网络路径或使用阻断外部流量的隔离环境，并记录阻断方式。
2. 从进程创建前开始记录应用相关进程、监听端点、连接尝试和 DNS 请求，持续到停止清理完成。
3. 分别执行配置页、Local O 核心闭环和 Local V 核心闭环；按冻结规则开始、观察结果、暂停/恢复并停止。
4. 核对核心操作结果、错误、端点清单和外部连接尝试；本机 IPC 与外部网络分开统计。

通过：核心闭环完成；无需账号/登录/在线下载；外部出站连接和 DNS 请求均为 0。数据缺失不得判定通过。

### NET-TEST-002：联网环境的静默外连观察

在允许网络但不执行任何安装/更新操作的隔离测试环境中，重复启动、配置、Local O / Local V 核心闭环、停止和诊断本地导出。以 OS 进程级网络记录核对域名、IP、协议、端口、方向、字节数和调用进程。任何外部连接均需与本表匹配；Local 没有核心外连允许项，因此预期为 0。

### NET-TEST-004：Online 授权上传与停止边界

选择 Online，记录用户点击开始、暂停、恢复、停止及切回 Local 的时点，核对 Provider 端点、载荷类别、请求数、上传字节数、错误和重试次数。通过：开始前无 Provider 请求；运行期只连接已选 Provider 并只发送必需音画；暂停后无新上传；停止、退出或切回 Local 后会话关闭且无新请求；网络、API、鉴权、配额或限流失败有明确反馈，重试次数不超过实现声明的上限。

### NET-TEST-003：监听面检查

枚举主程序、采集、模型和 Overlay 相关进程的监听端点。记录端点类型、绑定地址/命名空间、对端身份约束和用途。非本机接口监听、未登记端点或远程对端均失败；不因“未观察到连接”而省略监听检查。

## 7. 原始音画落盘检查

### DISK-TEST-001：默认运行差分快照

在干净测试账户中，记录应用安装区、应用数据区、系统临时目录和用户选择输出目录的测试前文件清单（路径类别、大小、修改时间和摘要）。执行 O/V 默认运行、暂停、恢复和停止后重新快照，检查新增/变更文件的文件类型、内容签名和来源。原始图像、视频或音频文件数必须为 0；扩展名缺失的文件也必须按内容签名检查。

### DISK-TEST-002：生命周期残留

重复执行开始→停止→再次开始→关闭，分别在每个边界检查 DATA-001～011 的允许位置、数量和清除结果。再次开始后上一运行轻量历史/高光记录为 0；关闭后滚动日志和运行期临时数据为 0；异常退出路径只允许 DATA-011 的最小锁标记，恢复处理后清除。

### DISK-TEST-003：诊断导出对照

分别生成默认诊断包和明确勾选弹幕文字的诊断包，解包后按内容清单和文件签名检查。两个包的原始图像/视频/音频均为 0；默认包弹幕文字为 0；勾选包只能增加用户界面已说明的弹幕文字条目。
