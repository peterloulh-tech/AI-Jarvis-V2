## 1. 判定标签

| 标签 | 含义 | 发布使用规则 |
|---|---|---|
| `FORMALLY_SUPPORTED` | 第一版正式支持并进入发布阻断矩阵 | 必须在规定真机组合逐项通过 |
| `NOT_FORMALLY_SUPPORTED` | 第一版不列入正式支持 | 不得在安装说明、UI 或宣传中暗示已支持 |
| `NOT_COMMITTED` | 当前不承诺结果，允许记录探索数据 | 探索成功不得自动升级为正式支持 |
| `EXPLICITLY_EXCLUDED` | 冻结范围明确不做 | 不得通过本任务增加实现或变体 |
| `REVIEW_REQUIRED` | 冻结文本冲突或出现未登记环境 | 记录证据并评审，不现场扩大支持范围 |
| `PASS` | 前置条件、操作、实际结果和证据完整，且满足适用期望 | 只代表该场景/组合本次通过 |
| `FAIL` | 可观察结果不满足适用期望或发生范围违规 | 不得由其他组合成功覆盖 |
| `DATA_INCOMPLETE` | 前置条件、操作、结果或证据任一缺失 | 不得判定通过或外推支持 |

## 5. 与任务4的边界

- 本任务定义支持边界、可复现环境和兼容表现；不新增故障信号、恢复状态或自动切换策略。
- 显示器/画面源失效引用 `REL-NFR-007` 与 `FAULT-008`；音频变化引用 `REL-NFR-008` 与 `FAULT-009`；Overlay 异常引用 `REL-NFR-009` 与 `FAULT-010/011`；锁屏、睡眠、休眠和唤醒引用 `REL-NFR-010` 与 `FAULT-014`。
- 本任务记录“在何种 Windows 条件下触发、用户看见什么、是否可复现”；任务4仍是暂停、停止、恢复、清理和故障不扩散动作的唯一来源。
- 不以“自动切换到其他显示器、窗口、麦克风或音频设备”伪装兼容成功。
