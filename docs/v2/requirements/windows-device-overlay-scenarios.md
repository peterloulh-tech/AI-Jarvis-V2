## 4. 禁止用自动切换掩盖失效

以下任一现象直接标记兼容失败或范围违规，不得用最终画面“看起来正常”覆盖：

- 运行中把失效窗口替换为显示器采集或其他窗口；
- 把断开的目标显示器替换为主屏，或把 Overlay 迁移到其他屏；
- 把失效麦克风/进程音频替换为默认设备、系统混合音频或其他进程；
- 通过新增窗口内 Overlay、跨显示器弹幕、自动 HUD 裁剪或托盘常驻规避场景失败。
