每次执行必须记录 Windows Build、GPU/驱动、显示器型号或稳定测试代号、物理连接、原生像素、方向、缩放、主屏、目标屏、采集源类型、游戏呈现模式和应用提交。改变任一条件必须创建新的 `sample_group`。

## 2. 单显示器与多显示器可复现拓扑

| ID | 拓扑前置条件 | 目标显示器 | 操作 | 可观察结果 |
|---|---|---|---|---|
| TOPO-001 | 单屏 1080P/100%，横向、主屏 | 唯一屏 | 启动显示器采集与 Overlay | 单源采集；Overlay 只在唯一屏显示 |
| TOPO-002 | 单屏 4K/200%，横向、主屏 | 唯一屏 | 启动显示器采集与 Overlay | 高 DPI 下坐标与点击穿透正确 |
| TOPO-003 | 双屏，均 1080P/100%，水平排列 | 主屏 | 依次在两屏点击，观察采集 | 主屏显示 Overlay；副屏不显示跨屏弹幕 |
| TOPO-004 | 双屏，均 1080P/100%，水平排列 | 副屏 | 依次在两屏点击，观察采集 | 副屏显示 Overlay；主屏不显示跨屏弹幕 |
| TOPO-005 | 2K/125% 主屏 + 4K/200% 副屏，水平排列 | 依次选择两屏，分两次运行 | 每次停止后重新选择目标再开始 | 每次只使用配置快照中的目标屏；混合 DPI 坐标正确 |
| TOPO-006 | 1080P/100% 横屏 + 2K/150% 竖屏 | 依次选择横/竖屏，分两次运行 | 执行横向和竖向显示区域样例 | 方向、边界、点击穿透正确；不跨屏 |

“多显示器”在第一版指系统可连接多个显示器，但每次运行仅选择一个采集源和一个 Overlay 目标显示器；不等于同时采集多屏或跨屏显示。

## 4. 结果规则

- 支持组合必须同时保留前置条件、操作、实际结果、截图/日志证据和 `sample_group`；缺任一项均为 `DATA_INCOMPLETE`。
- 全屏、无边框或窗口化场景若出现明确失效，只记录兼容结果并引用任务4故障行为；不得自动切换到其他窗口、显示器或采集方式后记为通过。
- 本矩阵不规定采集 API、窗口枚举方式、合成层或显卡互操作技术。
