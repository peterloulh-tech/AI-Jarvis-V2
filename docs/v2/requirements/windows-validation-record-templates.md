## 5. 采集、设备与系统事件记录

| 阶段 | 必须记录 | 通过条件 |
|---|---|---|
| 前置 | 稳定源标识、设备集合、显示拓扑、配置快照 | 条件可重复建立 |
| 操作 | 操作步骤版本、单调时间、Windows 事件 | 能关联到 scenario_id |
| 采集观察 | MP-07/08、帧/音频序列、实际源集合 | 与用户选定源一致 |
| Overlay 观察 | MP-17、可见性、几何、点击目标 | 逐项结果明确 |
| 失效观察 | MP-19、错误码、设备/拓扑变化 | 不自动切换掩盖失效 |
| 行为引用 | REL-NFR/FAULT ID、实际状态 | 不在本记录重写恢复动作 |
| 结论 | 正式支持标签、通过/失败、证据 | 失败不被其他组合覆盖 |
